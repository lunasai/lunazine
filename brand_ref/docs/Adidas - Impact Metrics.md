# Adidas - Impact Metrics
## Complete the Look: Product Recommendations Framework

**Senior Product Designer**  
**Adidas** | ~2020-2021  
**Focus:** Product discovery, recommendations system, conversion optimization

---

## Direct Revenue Impact

### **€3.69M Annualized Net Sales**
- **What:** "Socks candy aisle" test - recommending complementary socks with shoes purchase
- **Why it matters:** Previous attempts at this same feature had failed. Changed only the UI/interaction, not the product strategy
- **Innovation:** Proof that presentation matters as much as algorithm
- **Business outcome:** Global rollout based on single interaction design improvement
- **Visual comparison:** €3.69M from one small carousel = roughly **€307K per month** = **€10K per day** just from better UI. That's the power of interaction design at scale.

### **ROI Multiplier Potential**
- **Context:** If one touchpoint generated €3.69M, the full framework across all recommendation touchpoints has exponentially larger impact
- **Conservative estimate:** 3 recommendation types (Inspire, Guide, Complete) × multiple placements across journey = potential **10-20× the socks revenue** when fully implemented
- **Calculation:** If each major touchpoint performs even at 50% of socks success, full framework = **€18M-37M potential annual impact**

---

## System Efficiency & Consolidation

### **10+ → 1 Recommendation Component**
- **What:** Consolidated more than 10 different recommendation carousels into one shared, modular component
- **Why it matters:** Multiple versions = maintenance nightmare, inconsistent UX, code bloat
- **Technical achievement:** Single component supports **36+ design variations** through modularity (header layouts, aspect ratios, interaction patterns)
- **Impact:** Faster shipping, consistent UX, reduced engineering burden
- **Visual comparison:** Like having 10 different TV remotes for the same TV → one universal remote that works for everything. Engineers maintain one component instead of ten.

### **36+ Variations from 1 Component**
- **What:** Modular design system approach - headers, sizes, aspect ratios, interaction patterns all mix-and-match
- **Engineering efficiency:** 36 variations would normally require **36 separate components** (or endless prop drilling)
- **Maintenance reduction:** Instead of updating 10+ components for every change, **update once, propagate everywhere**
- **Visual comparison:** Like LEGO - one set of building blocks creates infinite combinations. This is the difference between tactical design (make 36 screens) and systems thinking (create one flexible system).

## Strategic Framework Creation

### **3 Recommendation Themes: Inspire, Guide, Complete**
- **What:** Shifted organizational mindset from "where do we place recommendations?" to "what does the user need right now?"
- **Why it matters:** Teams previously worked in silos with no shared language
- **Adoption:** Framework used by Browse & Delight designers + vertical teams across Adidas digital
- **Outcome:** Better decision-making, reduced redundant work, strategic product thinking vs. tactical feature drops

### **4-Pillar Decision Framework**
- **What:** Algorithm + Product Data + Visualization/Interaction + Placement
- **Why it matters:** Gave teams structured way to evaluate any recommendation opportunity
- **Impact:** Recommendations became repeatable, strategic decisions instead of one-off experiments
- **Visual comparison:** Like giving everyone a compass instead of arguing about which direction to walk. Teams can now make informed, aligned decisions independently.

## User Experience Impact

### **Journey-Mapped Recommendations**
- **What:** Mapped every recommendation touchpoint across full product discovery journey
- **Scope:** Homepage → PLP → PDP → Cart → Checkout
- **User benefit:** Right recommendation at right time (inspirational early, functional late in journey)
- **Before:** Recommendations felt random or irrelevant
- **After:** Contextual, purposeful suggestions that match user mindset

### **Curated Content Strategy**
- **What:** Two concepts tested - Curated Complete the Look + Adidas Stories
- **Innovation:** Balance between algorithmic and human-curated recommendations
- **Why it matters:** Algorithm alone can't capture brand storytelling and credibility
- **Partnership potential:** Creators, athletes, designers adding human connection to automated systems

## The Staff Designer Angle

### **Why This Is Platform-Level Work:**

**Problem scope:** Not just "design a carousel" - transformed how Adidas thinks about recommendations
**Business impact:** €3.69M proven, €18-37M potential across platform
**Cross-team influence:** Framework adopted by Browse & Delight + vertical teams
**Systems created:** Component system + strategic framework others now rely on
**Legacy:** Work continues after departure = foundational organizational change

### **Three Pivotal Decisions:**

**1. Started with quick win (socks), not grand vision**
- **Decision:** Test small, prove value, then scale
- **Impact:** €3.69M gave credibility to push for bigger systematic work
- **Learning:** Quick wins fund strategic work

**2. Built framework, not just features**
- **Decision:** Invested time in Inspire/Guide/Complete framework vs. shipping more one-off tests
- **Impact:** Organizational mindset shift from tactical to strategic
- **Learning:** Frameworks scale, features don't

**3. Partnered with Design System team for shared component**
- **Decision:** Don't create one-off component, make it systematic
- **Impact:** 36 variations from 1 component = scalable foundation
- **Learning:** Collaboration compounds impact
