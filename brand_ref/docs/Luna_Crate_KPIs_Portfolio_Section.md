## 2. Team Milestones I Led or Drove

These milestones are cited in Crate’s evolution; I owned the communication, design, or programme delivery.

### Figma Libraries 2.0 (Oct 2024)

- **What:** Full Figma library overhaul for eazle rebrand — new color categories (Club, Accent, Selected), improved token naming, better accessibility contrast.
- **Impact:** Questions volume rose in the following months (27 → 32 → **49 messages** Jan 2025); design system became the clear reference for the rebrand.
- **My role:** Announced and communicated the release to the community.

### First FE Developer Onboarding (Aug 2025)

- **What:** First-ever FE developer onboarding session; later extended to all roles (design, dev, PM, PO, QA).
- **Impact:** Review channel went from **9 messages (Sep)** to **48 messages (Oct)** — **+433%** — as onboarded contributors started posting review requests and engaging in the channel.
- **My role:** Led and announced the session; drove follow-up scaling with the team.

### Crate Connect — Weekly Cadence (Sep 2025)

- **What:** Moved Crate Connect from twice weekly to **weekly** during Crate Foundations; kept format open and inclusive.
- **Impact:** Sustained touchpoint for the community; aligned with peak engagement (Oct 2025).
- **My role:** Announced schedule change and maintained consistency of the programme.

### Crate Summer Updates (Aug 2025)

- **What:** Structured product-style update: Toast with progress bars, generic Card, deprecation process, Code Connect, Jira integration.
- **Impact:** 13 green heart reactions; marked shift from craft-focused updates to operational design infrastructure.
- **My role:** Wrote and published the Summer Update post; framed roadmap and collaboration ask.

### Loading Patterns & Guidelines (2025)

- **What:** Clear guidelines for loading states (UI State, Skeleton, Stepper) to move beyond basic spinners — documented in Announcements and Questions.
- **Impact:** Addressed 15–23 second load-time UX gap; product team (e.g. LoFu) took implementation ownership.
- **My role:** Set guidelines and drove documentation; aligned with EDS-201, EDS-202, EDS-203.

### Layout & Spacing System (Feb 2025 onwards)

- **What:** Layout Guidelines and semantic spacing system; cognitive design principles applied to platform visual language.
- **Impact:** Consistent spacing and layout; designer efficiency and clarity in Figma and Zeroheight.
- **My role:** Led Layout & Spacing System update comms and documentation; contributed to Figma and docs.
