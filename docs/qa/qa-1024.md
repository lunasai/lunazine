## Summary

The medium breakpoint now maps to `1024px` across code, preview, and design-system documentation. The previous medium audit was retired because it no longer represents the design-system medium mode.

| Check | Screenshot / token value | Code |

| `screen/max-width` | **1024** | `--screen-medium: 1024px`; medium CSS uses `@media (max-width: 1024px)` |
| `spacing/margins` | **40** | `--spacing-margin: 40px` at medium |
| `typography/display` | **72** | `--typography-display: 72px` inside the medium media block |
| `typography/title` | **56** | `--typography-title: 56px` inside the medium media block |
| Grid column reference | **64px** | `(1024px - 2 * 40px - 11 * 16px) / 12` |
